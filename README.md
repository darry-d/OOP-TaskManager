# Менеджер завдань (Task Manager) - Лабораторна робота №4

## Тема
Поліморфізм. Абстрактні класи. Перерахування (Enum). Records.

## Опис проєкту
Це консольний застосунок мовою Java для зручного управління списком завдань. Проєкт дозволяє створювати завдання різних типів, зберігати їх у файл та переглядати статистику. Архітектура побудована з дотриманням ключових принципів об'єктно-орієнтованого програмування (ООП).

## Що було реалізовано в межах ЛР №4:

1. **Абстрактні класи та поліморфізм:**
   Створено абстрактний базовий клас `Task` та два класи-нащадки: `RegularTask` (звичайне завдання) та `UrgentTask` (термінове завдання). Продемонстровано поліморфну поведінку через виклик методів `getTaskType()` та `getPriorityLevel()`.
2. **Перерахування (Enum):**
   Для статусів завдань створено enum `TaskStatus` (`TODO`, `IN_PROGRESS`, `DONE`) із власним полем для зберігання україномовного опису та перевизначеним методом `toString()` для красивого виводу.
3. **Методи equals(), hashCode() та toString():**
   Ці методи перевизначено для базового класу `Task` та його нащадків.
   *Обґрунтування:* Завдання вважаються ідентичними (`equals() == true`), якщо у них повністю збігаються назва (`title`) та дата дедлайну (`deadline`).
4. **Копіювання об'єктів (Shallow vs Deep):**
   У класі `Project` реалізовано конструктори для поверхневого (Shallow) та глибокого (Deep) копіювання. У головному меню додано окремий пункт [6], який наочно демонструє, що зміни в поверхневій копії впливають на оригінал, а глибока копія залишається незалежною.
5. **Records:**
   Створено два класи-записи (Records) для зручної передачі незмінних даних: `TaskFilter` (для параметрів фільтрації) та `TaskReport` (для проміжних даних звіту).
6. **Pattern Matching (instanceof):**
   У пункті меню [7] реалізовано проходження по загальному списку базового типу `Task` із використанням `instanceof` для визначення конкретного типу нащадка (підрахунок кількості саме `UrgentTask`). Результат пакується у record `TaskReport`.

## Функціонал меню (Інструкція з використання)
Після запуску `Main.java` користувачу доступні такі команди:
* `[1]` Показати завдання (сторінками)
* `[2]` Додати нове завдання (з вибором типу: Звичайне/Термінове)
* `[3]` Позначити як ВИКОНАНО
* `[4]` Видалити завдання
* `[5]` Зберегти та вийти
* `[6]` Демонстрація копіювання (Shallow vs Deep)
* `[7]` Згенерувати звіт (instanceof & Record)

# Менеджер завдань (Task Manager) - Лабораторна робота №8

## Тема
Колекції. Ітератори. Comparable/Comparator. Сортування.

## Опис проєкту
У межах восьмої лабораторної роботи оновлено внутрішнє зберігання даних застосунку «Менеджер завдань» із використанням основних типів колекцій Java Collections Framework, реалізовано власний ітератор із підтримкою `for-each`, додано кілька способів сортування, пошук за діапазоном дат через `NavigableMap`, власну реалізацію бінарного дерева пошуку (BST) та бенчмарк порівняння `ArrayList` і `LinkedList`.

## Що було реалізовано в межах ЛР №8:

1. **Типи колекцій за призначенням (`Project.java`):**
    - `List` (`ArrayList` у `Repository<Task>`) — основне сховище завдань зі збереженням порядку додавання та доступом за індексом.
    - `Map` (`HashMap<String, Task>`) — швидкий пошук завдання за його унікальним `id`.
    - `Set` (`HashSet<String>`) — зберігання унікальних дат дедлайнів без дублікатів.
    - `Queue` (`ArrayDeque<Task>`) — черга термінових завдань (FIFO) для послідовної обробки.

2. **Власний ітератор (`Project.java`):**
   Клас `Project` реалізує інтерфейс `Iterable<Task>`, а внутрішній клас `TaskIterator` реалізує `Iterator<Task>` (`hasNext()`, `next()`). Це дозволяє обходити завдання проєкту через розширений цикл `for (Task t : myProject)`.

3. **Сортування (`Task.java`):**
    - Природне впорядкування (`Comparable<Task>`) — сортування за датою дедлайну (а при однакових датах — за назвою).
    - `Comparator` (`Task.BY_TITLE`) — сортування за назвою завдання в алфавітному порядку.
    - `Comparator` (`Task.BY_PRIORITY`) — сортування за рівнем пріоритету (спочатку термінові).

4. **Пошук найближчого елемента та діапазону (`NavigableMap` / `TreeMap`):**
   Завдання групуються за `LocalDate` у `TreeMap`. За допомогою `ceilingEntry()` виконується пошук найближчого дедлайну від заданої дати, а через `subMap()` — вибірка всіх завдань у вказаному діапазоні дат.

5. **Власне бінарне дерево пошуку (`TaskBST.java`):**
   Реалізовано власну структуру BST з вузлами `Node` (`data`, `left`, `right`) без використання бібліотечних класів `java.util`. Підтримується вставка завдань за назвою та два обходи дерева: `in-order` (вивід за алфавітом) і `pre-order` (вивід ієрархії від кореня).

6. **Бенчмарк `ArrayList` vs `LinkedList`:**
   Проведено тест вставки та видалення 30 000 елементів у середину колекції за індексом:
    - `ArrayList`: вставка ~39 мс, видалення ~38 мс.
    - `LinkedList`: вставка ~452 мс, видалення ~381 мс.
    - **Висновок:** при роботі з серединою списку за індексом `ArrayList` працює значно швидше завдяки прямому доступу до індексу та оптимізованому зсуванню масиву, тоді як `LinkedList` на кожній операції змушений покроково проходити половину вузлів.

# Менеджер завдань (Task Manager) - Лабораторна робота №6

## Тема
Робота з рядками. Клас String. StringBuilder/StringBuffer. Регулярні вирази. Форматований вивід.

## Опис проєкту
У цій лабораторній роботі застосунок вдосконалено сучасними інструментами обробки тексту: додано можливість швидкого створення завдань із "сирого" рядка (CSV-імпорт), реалізовано генерацію акуратно вирівняного текстового звіту, додано жорсткі перевірки вхідних даних через регулярні вирази, а також проведено тест швидкодії (бенчмарк) різних методів конкатенації тексту.

## Що було реалізовано в межах ЛР №6:

1. **Імпорт/розбір вхідних текстових даних (Клас String):**
   Додано нову функцію "Швидке додавання (CSV-рядок)", яка приймає сирий текст від користувача та розбиває його на параметри для створення об'єкта. При цьому використано рівно 5 методів класу `String`:
    - `.split(";")` — розрізання рядка на складові масиву.
    - `.trim()` — очищення тексту від зайвих пробілів.
    - `.toLowerCase()` — нормалізація типу завдання для перевірки.
    - `.substring()` — безпечне обрізання занадто довгого опису завдання.
    - `.replace()` — автовиправлення роздільників дати (заміна `/` та `-` на `.`).

2. **Формування звіту (StringBuilder):**
   Створено красиву текстову таблицю-звіт із псевдографікою (рамками). Для її генерації застосовано понад 20 операцій `append()` класу `StringBuilder`. Це дозволило зліпити великий об'єм тексту в одному об'єкті без перевантаження пам'яті.

3. **Регулярні вирази (RegEx):**
   Написано та інтегровано 3 суворі патерни для валідації вводу:
    - `^\d{2}\.\d{2}\.\d{4}$` — строгий формат дати дедлайну (ДД.ММ.РРРР).
    - `^[^;]+$` — захист цілісності даних (заборона використання системного розділювача `;` всередині назви).
    - `^[12]$` — контроль вибору пункту меню (суворо цифра 1 або 2 для типу завдання).

4. **Форматований вивід (String.format та PrintWriter):**
   Колонки в текстовому звіті (ID, Тип, Дедлайн, Назва) ідеально вирівняні за допомогою форматування `%s` та специфікаторів ширини (наприклад, `%-12s`). Згенерований звіт автоматично записується та зберігається у фізичний файл `beautiful_report.txt` за допомогою потоку `PrintWriter`.

5. **Бенчмарк (Тест швидкості String vs StringBuilder):**
   Створено окремий пункт меню для тестування продуктивності. Програма виконує 100 000 ітерацій конкатенації символів за допомогою звичайного оператора `+` (клас `String`) та за допомогою `.append()` (клас `StringBuilder`), після чого виводить час у мілісекундах.
    - **Висновок тесту:** Доведено на практиці, що оскільки об'єкти `String` є незмінними, кожна операція `+` створює новий об'єкт у пам'яті, що страшенно гальмує програму. Натомість `StringBuilder` модифікує текст всередині існуючого об'єкта, тому виконує те ж саме завдання у сотні разів швидше (за лічені мілісекунди).

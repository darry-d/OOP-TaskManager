# Лабораторна робота №3 

**Тема:** Основи ООП, CRUD-операції, колекції та файлове введення-виведення.
**Варіант:** 7 (Система керування задачами - Task Manager)

## Реалізований функціонал:
* Створення, читання, оновлення статусу та видалення завдань (CRUD-операції).
* Пагінація списку завдань (посторінковий вивід).
* Збереження стану програми при виході та відновлення при запуску (Serialization/Deserialization).
* Автоматична валідація дати дедлайну із захистом від введення минулого часу.

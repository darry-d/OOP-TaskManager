# Менеджер завдань (Task Manager) - Лабораторна робота №5

## Тема
Обробка винятків. Узагальнення (Generics). Тип Optional.

## Опис проєкту
Це консольний застосунок мовою Java для зручного управління списком завдань. Проєкт дозволяє створювати завдання різних типів, зберігати їх у файл, здійснювати пошук та експортувати у текстовий формат. У цій лабораторній роботі архітектуру було вдосконалено з використанням сучасних механізмів безпеки та гнучкості мови Java для запобігання критичним помилкам під час виконання.

## Що було реалізовано в межах ЛР №5:

1. **Власна ієрархія винятків (Exceptions):**
   Створено базовий клас помилок домену `TaskManagerException` та два класи-нащадки: `TaskNotFoundException` (Checked-виняток для спроб видалення неіснуючого завдання) та `InvalidTaskDataException` (Unchecked-виняток для помилок введення невідомого типу завдання).
2. **Перехоплення винятків (try-catch):**
   Коректно оброблено понад 5 місць виникнення помилок у коді (перехоплення `NumberFormatException`, `DateTimeParseException`, `IOException` та власних виняткових ситуацій).
    - *Обґрунтування:* Для помилок введення (наприклад, неправильний тип завдання) реалізовано безперервний цикл запиту `while`, який запобігає аварійному завершенню програми та "добиває" користувача до введення правильних даних.
3. **Узагальнення (Generics з обмеженнями):**
   Реалізовано універсальний клас-сховище `Repository<T>`. Додано обмеження параметру типу `<T extends Identifiable>`, що дозволяє приймати лише ті об'єкти, які підписали відповідний інтерфейс і гарантовано мають метод `getId()`. Репозиторій замінив стандартний `ArrayList` у класі `Project`.
4. **Безпечний пошук (java.util.Optional):**
   Повністю усунуто повернення `null`. У класі `Project` реалізовано три методи (`findTaskByTitle`, `findTaskById`, `findFirstUrgentTask`), які повертають сучасний контейнер `Optional<Task>`. На стороні виклику (у меню) додано безпечну перевірку та розпаковку результатів через метод `.isPresent()`.
5. **Використання Wildcards (? extends) та try-with-resources:**
   Створено узагальнений метод експорту завдань у текстовий файл `exportTasksToTxt(List<? extends Task> tasks, String filename)`. Завдяки `? extends` метод є універсальним і здатен обробляти списки будь-яких об'єктів-спадкоємців класу `Task` (наприклад, суто `UrgentTask`). Для автоматичного закриття потоків запису використано конструкцію `try-with-resources`.

## Функціонал меню (Інструкція з використання)
Після запуску `Main.java` користувачу доступні такі команди:
- `[1]` Показати завдання (сторінками)
- `[2]` Додати нове завдання (із циклічним захистом від неправильного вводу)
- `[3]` Позначити як ВИКОНАНО
- `[4]` Видалити завдання (із перевіркою існування через TaskNotFoundException)
- `[5]` Зберегти та вийти
- `[6]` Демонстрація копіювання (Shallow vs Deep)
- `[7]` Згенерувати звіт (instanceof & Record)
- `[8]` Безпечний пошук (Optional)
- `[9]` Експорт завдань у TXT (Wildcard & try-with-resources)
